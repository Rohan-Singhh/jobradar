Run Job Radar on your own computer

The hosted app is the quickest way in. Running it yourself adds what a website that stores nothing cannot do: a daily email when a role opens at a company you care about, and a ranked digest every Monday.

What you need

  • Python 3.11 or newer
  • On Windows, Git for Windows; the scripts run in its Git Bash
  • Your resume as a PDF
  • A free API key from xkiro
  • For email, a Gmail account with an App Password

Windows

In PowerShell:

git clone {{ site.source }}.git
cd jobradar
powershell -ExecutionPolicy Bypass -File install.ps1

This creates the Python environment, config.yaml and run.sh, and adds two Task Scheduler jobs. Run every ./run.sh command from Git Bash.

macOS

Clone into your home folder; macOS blocks background jobs from reading Desktop and Documents.

cd ~
git clone {{ site.source }}.git
cd jobradar
./install.sh
cp run.example.sh run.sh

Add your details

  1. Copy your resume PDF into the folder and set resume_path in config.yaml.
  2. Put your Gmail address in email.to and email.from, and list the companies you want daily alerts for under alerts.companies.
  3. Open run.sh and paste in your xkiro key and Gmail App Password.

Run it

./run.sh test     # sends a test email
./run.sh scan     # fetch every board and score the jobs
./run-web.sh      # the app, at http://localhost:8765

The first scan scores every open role and uses roughly 150,000 to 350,000 tokens of the free daily allowance. Later scans only score what is new.

What runs on its own

  • Every day at 09:30: checks your shortlist and emails you if a strong match opened.
  • Every Monday at 09:00: a full scan and a ranked digest of the week's new roles.

The first alert run sends nothing: it records what is already open, so you are not emailed about postings that have been up for months.
